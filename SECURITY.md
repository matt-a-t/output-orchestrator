# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue: on the repository's
[Security tab](https://github.com/matt-a-t/output-orchestrator/security), choose
**Report a vulnerability**. Only the maintainer sees the report.

Include what you found, how to reproduce it, and the version of `output-orchestrator` you saw it
in. You'll get a reply there, and a fix is released before the report is made public.

## Supported versions

Fixes go into the latest release on npm. Update with `npm install -g output-orchestrator@latest`.
